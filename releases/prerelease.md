# RocketLantern preview

This is an automatically built pre-release for testing upcoming changes.
It may contain bugs or unfinished features and is not recommended for
everyday use. Back up your local data before testing it.

Download the Windows installer (`setup.exe`) or the portable ZIP below.
No Python installation is required.

For the latest stable version, visit
[the stable release](https://github.com/akerfourn/rocket-lantern/releases/latest).

Please report problems through the repository's Issues page, mentioning
the version and steps needed to reproduce the issue.
